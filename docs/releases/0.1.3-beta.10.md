Mikan **0.1.3 beta.10**, build **10201023**.

- **Nothing in a server row is cut short:** in the node picker a server's name gets two lines and the whole width, the check of the selected server sits on the corner of its flag, and REALITY is no longer clipped. The server group badge stays beside the protocol chips while it fits and takes a line of its own when it does not.
- **Server groups on Home and in the subscription sheet:** a group's name and what is left of its traffic share a line while they fit; otherwise what is left moves under the name, so a large font no longer cuts the name to a few letters.
- **Add from a mikan panel:** the subscription page of a mikan panel 0.5.2.0 or newer opens Mikan with a `mikan://` link that no other app takes.

Version **0.1.3**, application ID **io.github.miroshka000.mikan**, build **10201023**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.

This pre-release does not replace the latest stable release.
