Mikan **0.2.0**, build **10201030**.

- **Android TV:** Mikan now fits a TV. Navigation moves to a rail on the left, one accent ring follows the remote's D-pad, Home uses two columns and the server picker opens as a panel on the right. Things a remote cannot use (camera, clipboard, rule and config editors) are hidden; Settings → **Advanced tools on TV** brings the editors back.
- **Remote for your TV:** "+" → **Control a TV** pairs the phone with Mikan on a TV in the same network and opens a remote: turn the TV's VPN on and off, pick servers and test them, switch the mode and the profile, update providers, look at and close connections, watch live traffic.
- **Subscription updates, your way:** Settings → App → **Subscription updates**. Turn automatic updates off (subscriptions then update only when you tap Update), choose which failures notify you (all, only an expired subscription or the device limit, or none), opt into a notification after a successful update, hide the progress notification and mute in-app messages about background updates.
- **No more piles of update errors:** each subscription keeps at most one result notification. A newer failure replaces the old one, and the next successful update, including one you start yourself, removes it.
- **App proxies:** Rules → App proxies. Add your own SOCKS5 or HTTP proxies and send chosen apps through one of them, through a server or group of the subscription, straight past the VPN, or block them. If an app's proxy cannot be used, the app is blocked instead of leaking.
- **Kill switch:** Settings → Network → Security → Kill switch. If the VPN stops on its own, Mikan keeps an empty tunnel up so no app reaches the network until you reconnect or disconnect.
- **Expanded list on Home:** an option in personalization shows every proxy group and its servers right on Home; tap a group header to fold it, tap a server to pick it.
- **Reliable subscription refresh:** an update tries the regular Internet first and retries through the proxy after a network failure. Connected now means ready: Mikan no longer says Connected before the profile is loaded and the tunnel is up.
- **Beta versions and updates at launch:** Settings → App → Beta versions. Mikan looks for a newer build on your channel at every start and downloads the APK for your phone's processor.
- **Core:** Citrus updated to dev `c134f2e2`: `tls.ca-roots` / `tls.ca-denylist` (refuse certificate chains through state interception CAs), XDrive local and template storage refused from HTTP providers, and fixes for DNS, Mux.Cool, XHTTP, TUIC, AnyTLS and the GEO updater.
- **Fixes:** App Routing lists preinstalled apps that have an icon; picking a server activates the profile Home shows when none is active; the shown tab stays put when tabs change; operator logos no longer waste memory; the rules editor no longer adds an empty `rule-providers` block; a tap on a server's name picks it.
- **Requirements:** Android 6.0 (API 23) or newer; Android 5 is no longer supported.

Mikan **0.2.0**, сборка **10201030**.

- **Android TV:** Mikan теперь подходит для телевизора. Навигация переехала в панель слева, за пультом следует одно цветное кольцо фокуса, главная разбита на две колонки, а выбор сервера открывается панелью справа. То, чем с пульта не воспользоваться (камера, буфер обмена, редакторы правил и конфига), скрыто; «Настройки → **Расширенные инструменты на ТВ**» возвращают редакторы.
- **Пульт для ТВ:** «+» → **«Управление ТВ»** сопрягает телефон с Mikan на ТВ в той же сети и открывает пульт: включить и выключить VPN на ТВ, выбрать и проверить серверы, переключить режим и профиль, обновить провайдеров, посмотреть и закрыть соединения, следить за трафиком.
- **Обновление подписок по-вашему:** «Настройки → Приложение → **Обновление подписок**». Автообновление можно выключить (тогда подписки обновляются только по кнопке «Обновить»), выбрать, о каких ошибках сообщать (все, только истёкшая подписка и лимит устройств, или никакие), включить уведомление об успешном обновлении, скрыть уведомление о процессе и сообщения в приложении о фоновых обновлениях.
- **Ошибки обновления больше не копятся:** у каждой подписки максимум одно уведомление. Новая ошибка заменяет старую, а следующее успешное обновление, в том числе ручное, её убирает.
- **Прокси для приложений:** «Правила → Прокси для приложений». Добавьте свои SOCKS5- или HTTP-прокси и отправьте выбранные приложения через один из них, через сервер или группу подписки, напрямую мимо VPN, или заблокируйте их. Если прокси приложения нельзя использовать, приложение блокируется, а не идёт в обход.
- **Kill switch:** «Настройки → Сеть → Безопасность → Kill switch». Если VPN остановился сам, Mikan держит пустой туннель, и ни одно приложение не выходит в сеть, пока вы не переподключитесь или не отключитесь.
- **Развёрнутый список на главной:** режим в персонализации показывает группы и серверы прямо на главной; нажатие на заголовок группы сворачивает её, на сервер выбирает его.
- **Надёжное обновление подписок:** сначала обычный интернет, после сетевой ошибки повтор через прокси. «Подключено» теперь значит «готово»: Mikan не пишет «Подключено», пока профиль не загружен и туннель не поднят.
- **Бета-версии и обновления при запуске:** «Настройки → Приложение → Бета-версии». При каждом запуске Mikan ищет более новую сборку на вашем канале и качает APK под процессор телефона.
- **Ядро:** Citrus обновлён до dev `c134f2e2`: `tls.ca-roots` / `tls.ca-denylist` (отказ от цепочек через государственные CA для перехвата трафика), отказ от XDrive local и template из HTTP-провайдеров, исправления DNS, Mux.Cool, XHTTP, TUIC, AnyTLS и обновления GEO.
- **Исправления:** App Routing показывает предустановленные приложения со значком; выбор сервера включает профиль, который показан на главной, если активного нет; открытая вкладка не сбрасывается при смене набора вкладок; логотипы операторов больше не тратят память зря; редактор правил не дописывает пустой `rule-providers`; сервер выбирается тапом по названию.
- **Требования:** Android 6.0 (API 23) и новее; Android 5 больше не поддерживается.
