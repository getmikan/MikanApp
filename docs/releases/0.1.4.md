Mikan **0.1.4**, build **10201025**.

- Updated the interface with expressive Material 3 surfaces, an animated mandarin connection button, a compact navigation capsule and theme palette previews.
- Server names, group labels and protocol badges wrap without clipping. Country flags, group filters and saved server order keep subscriptions easier to navigate.
- Compatible Mikan panels can supply per-group traffic, reset dates and top-up actions. Their subscription pages open the app with `mikan://` links.
- Improved subscription refresh feedback, automatic refresh timing and active-profile handling.
- Updated the bundled Citrus core, including transport, TrustTunnel and geodata compatibility fixes.
- Target Android 16 / API 36. Enable edge-to-edge consistently, protect content around display cutouts and system bars, and use the AndroidX back dispatcher for navigation. Bottom actions in the rules editor stay above three-button navigation.

Google Play bundles require **Android 7.0 / API 24** for Play automatic protection; direct APK builds retain **Android 5.0 / API 21** support.

Application ID: **io.github.miroshka000.mikan**. The existing release signing certificate is retained. `alpha` in an APK filename is the build flavor, not a package suffix. Updating between Play and GitHub also requires compatible signing certificates.
