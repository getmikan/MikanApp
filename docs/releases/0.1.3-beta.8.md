Mikan **0.1.3 beta.8**, build **10201021**.

- **Server groups of a mikan panel.** A subscription from a mikan panel shows each server group with traffic of its own. Home: a line per group under the main traffic, with what is left and the used share. The subscription sheet: "Server groups" with the traffic used of the total, what is left in packages, when the traffic starts over, and "Buy more traffic" for a group that ran out. The node picker: the group's badge on each of its servers, a filter per group, and a notice when a group ran out and its servers left the profile.
- The app asks for the groups with the `X-Mikan-Features: groups` request header; a mikan panel answers with `X-Mikan-Groups` beside the profile (mikan 0.5.1.1-rc.15 or newer). Other panels ignore the header, and nothing changes for their subscriptions.

Version **0.1.3**, application ID **io.github.miroshka000.mikan**, build **10201021**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.
