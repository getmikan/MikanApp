Mikan **0.1.5 beta.4**, build **10201029**.

- **A tap on a server picks it:** tapping a server's name in the server list selects it again; before, only the edges of the row did. The server lists of Proxy chain and App proxies are fixed the same way.
- **Beta versions:** Settings → App → Beta versions. With it on, Mikan updates to beta builds too; off, only to stable releases.
- **Updates at launch:** every time Mikan starts, it looks for a newer build on your channel. If there is one, it downloads at once and opens the installer; if not, nothing is shown. The download is the APK for your phone's processor (about 47 MB instead of 129 MB). Android still asks you to confirm the install.

Install this beta by hand once: earlier builds only look for stable releases. The betas after it arrive on their own with **Beta versions** on.

Version **0.1.5**, application ID **io.github.miroshka000.mikan**, build **10201029**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.

This pre-release does not replace the latest stable release.
