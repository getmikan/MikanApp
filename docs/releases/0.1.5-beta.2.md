Mikan **0.1.5 beta.2**, build **10201027**.

- **One natural Home scroll:** the expanded server list no longer has its own nested scrolling area or fixed height. It moves together with the whole Home page.
- **Controls before content:** subscription actions and the Rule/Global selector now stay above the expanded server list, so they remain easy to reach.
- **Collapsible groups:** tapping a proxy-group header now collapses or expands its servers, with the state preserved while latency results and selections update.

Version **0.1.5**, application ID **io.github.miroshka000.mikan**, build **10201027**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.

This pre-release does not replace the latest stable release.
