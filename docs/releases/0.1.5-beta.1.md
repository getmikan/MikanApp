Mikan **0.1.5 beta.1**, build **10201026**.

- **Reliable subscription refresh:** updates now try the regular Internet first and retry through the proxy after a route-shaped network failure. A connection reset while the response body is downloading is covered too; an error is shown only after both routes fail.
- **The connected state means ready:** Mikan no longer reports the tunnel as connected before the active profile is loaded and TUN is attached. This removes the startup window where the UI said Connected while traffic could not pass.
- **Expanded list on Home:** a new personalization option shows every selectable proxy group and its servers directly on Home. Servers can be selected in one tap without opening the picker; protocol badges, latency checks and large-list recycling are preserved.

Version **0.1.5**, application ID **io.github.miroshka000.mikan**, build **10201026**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.

This pre-release does not replace the latest stable release.
