Mikan **0.1.3 beta.7**, build **10201020**.

- Updated Citrus to `dev` commit **ca8204d95c32664303a00ba917a45df8254adb1f** with the GeoIP/GeoSite/MMDB/ASN compatibility fix. Bundled and downloaded databases no longer require a SHA-256 pin; explicitly configured pins are still checked.
- Added native Android integration regressions for bundled databases, missing-file downloads, manual updates and rejection of incorrect pins without damaging the installed file.

Version **0.1.3**, application ID **io.github.miroshka000.mikan**, build **10201020**. The release signing key is unchanged. Use **mikan-alpha-arm64-v8a.apk** for a modern Android phone, or **mikan-alpha-universal.apk** for all architectures. Checksums: **SHA256SUMS.txt**.

This pre-release does not replace the latest stable release.
